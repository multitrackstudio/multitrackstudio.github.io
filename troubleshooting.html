MultitrackStudio not recording? The documented fixes for common problems

Updated: 2026-11-07

When MultitrackStudio is not recording, records the wrong thing, drifts out of sync or stops with a buffer error, the vendor's troubleshooting chapter usually has the answer. Here are those fixes, grouped by symptom, with the exact settings to change.

If MultitrackStudio is not recording on Windows 10 or 11, allow apps to access your microphone in Settings > Privacy, and check that a device is selected in Studio > Devices. Buffer over/underrun messages usually go away when you close other programs. Tracks out of sync are fixed by a newer driver, a 48 kHz song rate or a different driver type.

MultitrackStudio not recording, or recording silence

The most common reason MultitrackStudio is not recording on Windows 10 and 11 is privacy settings. Open Start > Settings > Privacy and turn on the option that allows apps to access your microphone. Without it, the track records but the file stays silent.

If a track's Play or Rec button turns gray when the Transport starts, no audio or MIDI device is available for that track's file. Open the Studio menu, choose Devices and select a device for input and output. Check also that the interface is connected before you start the program.

The recording contains the wrong sound

Two problems come from how the sound device and the files are set up, not from the program.

  • Other tracks appear inside the track you just recorded: the sound device is recording its own output. Open the sound device's own mixer or control panel and turn off the loopback or what you hear input.
  • Vocals play in one speaker only: the vocal was recorded to a stereo file, so one channel is silent. Add the track as a mono audio file before recording a single microphone.

Glitches, static and buffer errors

Clicks, static, a MIDI device that pauses, or the Transport stopping with a Buffer over/underrun message all point to the computer not keeping up. The vendor's fix is to close all other programs. If that is not enough, compare your machine with the MultitrackStudio system requirements: high sample rates and many plugins need a faster processor, and larger songs benefit from a faster drive.

On Windows with an ASIO driver, glitches that appear when you open windows or click around can be reduced by turning on MMCSS, which the manual describes in its chapter on compensating for driver issues.

Tracks out of sync or playing too fast

When newly recorded tracks drift against earlier ones, the vendor suggests working through these steps in order.

  1. Install the latest driver for your sound device.
  2. Change the song's sample rate from 44.1 kHz to 48 kHz in Song Properties.
  3. On Windows, try a different driver type in Studio > Devices.
  4. On Windows with an early driver type and a Sound Blaster Live or similar card, turn on EMU10k1 44.1 kHz Sync Correction in Devices; turn it off on other cards.
  5. On a Mac with separate recording and playback devices, build an aggregate device in Audio MIDI Setup and use that.

If songs play back too fast, the sample rate in the sound device's control panel does not match the one in Song Properties. Make them the same. On Windows, also set the Sound Scheme to No Sounds in the Control Panel so system sounds do not change the device rate.

Other programs and files

The export steps that avoid the CD and MIDI file problems are on our how to record with MultitrackStudio page.

  • Other programs go silent while MultitrackStudio runs: turn on Shared mode in the Devices window (Windows 10 or newer).
  • A CD writing program will not load the master: export a stereo WAV file, and in Pro choose 16 bit.
  • Another program cannot load your MIDI files: set MIDI File Format to 480 ticks per quarter note in Preferences.
  • You need an earlier version of a file: MultitrackStudio makes a backup on every save with a ~ before the extension, so song.hdr is backed up as song.~hdr. Rename the backup to the original extension to restore it.

When the fixes do not help

Version 11.4.2 added a Send Report Now button in the Contact window, which sends a report to the vendor from inside the program. The vendor's site also has a contact page and a user forum. Before writing, update to the latest version from the MultitrackStudio download page; updates are free for licence holders, and the release notes list fixes such as playback over Remote Desktop with the Windows driver type.

If the program still does not fit your hardware, our MultitrackStudio review sums up where it is strong and where it is limited.

FAQ

Why is MultitrackStudio recording silence?

On Windows 10 and 11 the usual cause is that apps are not allowed to use the microphone. Turn it on in Start > Settings > Privacy, then check your input in Studio > Devices.

What does Buffer over/underrun mean in MultitrackStudio?

The computer could not deliver audio to the sound device in time. The vendor's advice is to close all other programs; a faster machine helps with high sample rates.

Why is the Rec button gray?

No audio or MIDI device is available for that track's file. Choose a device in the Devices window under the Studio menu.

Why do other apps go silent when MultitrackStudio is open?

The program has exclusive use of the sound device. Turn on Shared mode in the Devices window, which needs Windows 10 or newer.

How do I restore an older version of a song file?

MultitrackStudio keeps a backup on each save with a ~ added before the extension, such as .~hdr. Rename the backup to the original extension to use it.

Why do my tracks drift out of sync?

Usually a driver issue. Install the latest driver, try 48 kHz in Song Properties, or switch driver type in Devices; on Mac, use an aggregate device if input and output are separate devices.
