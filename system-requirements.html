MultitrackStudio system requirements: Windows, Mac, ARM, drivers and plugins

Updated: 2026-11-07

The MultitrackStudio system requirements are light: Windows 11 to 7 or macOS back to OS X 10.11, any full duplex sound device and a reasonably fast processor. This page collects the operating systems, drivers, plugin formats and hardware advice from the vendor.

Key facts

  • Windows:11, 10, 8, 7, 64 and 32 bit
  • Windows on ARM:Windows 11, ARM64EC
  • Mac:macOS 27 to OS X 10.11
  • Apple Silicon:Native, Universal Binary
  • CPU cores used:Up to 8
  • RAM:Not specified
  • Checked:2026-11-07

MultitrackStudio runs on Windows 11, 10, 8 and 7 (64 bit, 32 bit and ARM64) and on macOS 27 back to OS X 10.11, natively on Apple Silicon and Intel. You need a sound device that plays and records at once at 16 bit, 44.1 kHz. The vendor gives no RAM or screen minimum and recommends a fast processor and a 7200 RPM drive for larger songs.

Operating systems

The MultitrackStudio system requirements cover old and new machines. On Windows there is a 64 bit build for 64 bit Windows 11, 10, 8 and 7, and a 32 bit build that runs on any of them. Windows on ARM is supported natively on ARM64 Windows 11; the program is built as ARM64EC, so x64 plugins still load.

On Mac the program is a Universal Binary for Apple Silicon and Intel. The vendor's requirements and download pages list macOS 27 back to 10.12 plus OS X 10.11; the tech specs page still names macOS 26 as the newest, which looks like a page that has not caught up. There is no Linux version.

Processor, memory and disk

The vendor does not give a CPU model, a RAM figure or a screen size. It says realtime audio needs a fast processor, that most current computers are suitable, and that 96 or 192 kHz work needs a faster machine as well as the Pro edition. The engine spreads work over up to eight CPU cores.

Memory needs are described as modest unless you load very large sampler patches, and plugins can use far more memory than the program itself. For songs with around ten audio tracks the vendor recommends a 7200 RPM hard drive over a 5400 RPM one; an SSD exceeds that easily.

Sound device and drivers

The minimum is a sound device that handles 16 bit, 44.1 kHz stereo in full duplex, meaning it plays and records at the same time. The built in device works, but the vendor recommends a good quality interface. Windows driver types are ASIO, WASAPI (listed as Windows Drivers in the manual), MME and DirectSound; Mac uses Core Audio.

  • Cheap interfaces with 3.5 mm jacks may need adapters for XLR or 6.3 mm microphones
  • An external mic preamp improves quality and often supplies phantom power for condenser mics
  • Some stereo devices cannot set left and right input levels separately; two preamps or a small mixer solve that
  • On a Mac with separate input and output devices, an aggregate device in Audio MIDI Setup keeps them in sync

Plugin formats and MIDI

On 64 bit Windows, MultitrackStudio hosts CLAP, VST3 and VST2 (32 and 64 bit) plugins. On Mac it hosts Audio Unit v2 and v3, CLAP, VST3 and VST2, all 64 bit. ARA 2 works with CLAP, VST3 and AU, which matters for pitch editors that use it.

MIDI 1.0 works on every supported system. MIDI 2.0 needs 64 bit Windows with the Windows MIDI Services runtime, or macOS 11 and newer. FLAC files need Windows 10 or macOS 11, and MP3 on Windows 7 needs an extra encoder.

Requirements that depend on the edition

Some limits come from the licence, not the computer. Lite and Standard record two channels at once at 44.1 or 48 kHz into 16 bit files; Pro records up to 140 channels, up to 192 kHz, into 24 bit or 32 bit float files. A multichannel interface is only fully used with Pro, so check the MultitrackStudio pricing page before you buy hardware or a licence.

Once your system checks out, get the installer from the MultitrackStudio download page and run the vendor's quick start, rewritten on our how to record with MultitrackStudio page. Glitches and sync problems are covered in MultitrackStudio troubleshooting.

FAQ

Does MultitrackStudio run on Windows 11?

Yes. Both the 64 bit and 32 bit builds support Windows 11, 10, 8 and 7, and there is a native ARM64EC build for Windows 11 on ARM.

Does MultitrackStudio run natively on Apple Silicon?

Yes. The Mac version is a Universal Binary for Apple Silicon and Intel, both 64 bit. The vendor supports macOS 27 back to OS X 10.11.

How much RAM does MultitrackStudio need?

The vendor does not give a figure. It says memory needs are modest unless you use very large sampler patches, and that plugins can use much more memory than the program.

Does MultitrackStudio support ASIO?

Yes. On Windows it supports ASIO, WASAPI, MME and DirectSound. On Mac it uses Core Audio.

Is there a Linux version?

No. The vendor offers Windows, Mac and an iPad version, but no Linux build.

Can I use 32 bit VST plugins?

On Windows, yes: the 64 bit build hosts 32 and 64 bit VST2 plugins. On Mac all plugin formats must be 64 bit.
