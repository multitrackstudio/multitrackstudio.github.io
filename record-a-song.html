How to record with MultitrackStudio: from an empty song to a mixed file

Updated: 2026-11-07

How to record with MultitrackStudio, using the menu names from the vendor's quick start and mixdown chapters: set the devices, build a song track by track, mix it and export it.

Key facts

  • Devices:Studio > Devices
  • New song:Song > New
  • Add a track:Add Track menu
  • Export:Mix Down > Mix down to audio file
  • Check the mix:Mix Down > Playback mixed down file
  • Checked:2026-11-07

To record with MultitrackStudio, choose your sound device in Studio > Devices, start a song with Song > New, add tracks from the Add Track menu, press a track's Rec button and start the Transport. When all parts are in, set levels and effects and use Mix Down > Mix down to audio file to export the song.

Before you start

Learning how to record with MultitrackStudio starts with the hardware. The vendor's minimum is a sound device that plays and records at the same time at 16 bit, 44.1 kHz, which almost any current interface does. A dedicated interface works better than the built in one, a microphone is needed for audio and a MIDI keyboard for MIDI.

Install the program from the vendor's site first; our MultitrackStudio download page has the file sizes. Lite is enough to follow this guide, since it allows three tracks.

  • A sound device that records and plays at once
  • A microphone, and a preamp if your interface has no mic input
  • Headphones, so the click and earlier tracks do not leak into the microphone
  • On Windows 10 and 11, microphone access allowed in Settings > Privacy

Record a song step by step

  1. Choose your devices: Open the Studio menu and pick Devices. Select your audio interface and MIDI keyboard. On Windows, ASIO or the Windows driver type usually gives the lowest latency.
  2. Create a song: Choose Song > New. MultitrackStudio creates a folder for the song automatically.
  3. Add a click track: Open the Add Track menu and choose Click Track so you can play in time.
  4. Add a track: Use the Add Track menu again to add an empty audio or MIDI track. For a single microphone choose a mono audio file, so the vocal is not stuck in one side.
  5. Arm and set the level: Click the track's Rec button. If your sound device allows it, a recording level fader appears at the top of the window; the Input button also opens the level controls.
  6. Record: Start the Transport, play or sing along with the click, and stop the Transport when you finish.
  7. Build up the song: Add the next track and repeat. Earlier tracks play while you record the new one. Add reverb to vocals through an Effect Return section.
  8. Mix down: Set volumes and effects, then choose Mix Down > Mix down to audio file. Use Mix Down > Playback mixed down file to check the result.

Export options in Mix down to audio file

The mixdown window has Start and End boxes, and the small arrows beside them load marker positions, so you can export just a section. Browse sets the file name and folder, Type sets the format, and Quality appears when a format has several quality levels. More reveals extra options: mono output, a different sample rate than the song's, the noise shaping switch for the dither and Remember Folder.

Formats depend on the edition. Lite exports 16 bit WAV and AIF; MP3, FLAC and M4A export starts at Standard, and 24 bit and 32 bit float files are Pro only. The MultitrackStudio pricing page lists the full line.

  • For a CD, export a stereo 16 bit WAV file
  • Pro users with VariSpeed set will see Include Varispeed, which is on by default
  • Record MIDI tracks that use an external MIDI instrument to audio first, or they will be missing from the mix

Recording MIDI instead of audio

A MIDI track records notes from a MIDI keyboard, the computer keyboard or a touchscreen. It plays through the built in MultitrackStudio Instruments (General MIDI sounds), the sampler or SoundFont player, external MIDI hardware, or a VST, CLAP or AU instrument plugin. After recording, edit the notes in the piano roll, score, drum or pattern editors.

If you plan to open your MIDI files in another program, set MIDI File Format to 480 ticks per quarter note in Preferences; the vendor lists this among its fixes.

When something goes wrong

The most common first session problems are a silent recording, the new take appearing on other tracks, and buffer errors. Each has a documented fix on our MultitrackStudio troubleshooting page. If the program is slow or glitchy, check your computer against the MultitrackStudio system requirements, especially the advice on disk speed and closing other programs.

FAQ

How do I export an MP3 from MultitrackStudio?

Choose Mix Down > Mix down to audio file and set Type to MP3. MP3 export needs Standard or Pro, and on Windows 7 an MP3 encoder must be installed.

Why is my vocal only in one speaker?

It was recorded to a stereo file, which leaves one channel silent. Record vocals and other single microphones to mono audio files.

How do I add a click track?

Open the Add Track menu and choose Click Track. It plays while you record so you can keep time.

Can I record several instruments at once?

Yes, up to two channels at once in Lite and Standard. Pro records up to 140 channels at once, depending on how many inputs your sound device has.

How do I check my mix after exporting?

Choose Mix Down > Playback mixed down file. It closes the current song and opens the exported file in a new song for listening.

Do I need Pro to make a CD?

No. Any edition can export a stereo 16 bit WAV file, which is what CD burning software needs. Pro users must remember to choose 16 bit when exporting.
